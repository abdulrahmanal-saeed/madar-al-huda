A pending legacy issue currently blocks all library publication. Direct MCP publication calls the same updateLibrary function. Do not grant new structured content publication via the legacy path.

- `apps/mobile/lib/features/fiqh/presentation/fiqh_screen.dart` wraps ManagedContentScreen; legacy entries contain title and positions with school/body/source. ManagedLibraryProvider uses ETag, offline cached feed and version gating. Existing search normalization: core/localization/search_text.dart. Reuse navigation, localization, and responsive content.

- Hostinger code-only deployment is triggered by main; it preserves private SQLite, seeds and settings. Public website currently has landing/app/privacy pages. Mobile CI already lints PHP and runs Flutter tests and debug builds.

## Draft contract
Use bilingual objects `{ar,en}` with original Arabic unchanged. Issue identity (id, number, slug, categoryId, subcategoryId, relatedCategoryIds, relatedIssueIds), title/summary/introduction/scope, keywords, displayOrder/difficulty, revision/time metadata. Positions keyed by hanafi/maliki/shafii/hanbali with ruling/explanation/reasoning, conditions, exceptions, alternative opinions, documented classification, evidenceIds and sourceReferences. Evidence with stable ID, type, bilingual text/reference/explanation, sourceIds, applicable schools, optional Quran/hadith identifiers, grading and attribution, URL. Citation locators are revision-specific and must identify edition and page/chapter as applicable; unknown bibliographic placeholders cannot satisfy scholarly completeness. Agreement/disagreement/reasons each use explicit applicable flag with bilingual entries or bilingual N/A justification. Scholarly summary, examples, notes and terminology are separate bilingual fields. Never derive consensus from school agreement. No preferred-opinion ranking or AI approval.

This is a preliminary contract; complete structural schema, foreign keys, publication gates and integrations remain open. Seed descriptions and author/edition metadata are deliberately blank pending verified editorial data. No APK, migration, website deployment or CI success is asserted by this document.
